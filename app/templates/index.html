What the Application Actually Sees

The application only reads a local file. Vault authentication and credential lifecycle management are handled outside the application process.
Application container | | read() v /vault/secrets/db-creds.json | | rendered by v Vault Agent sidecar | +--> Kubernetes Auth | +--> Vault Database Secrets Engine | +--> demo-agent-reader | +--> PostgreSQL | +--> lease management
